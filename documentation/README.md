# Documentation MegaFinder

Les fichiers déposés dans ce dossier restent sur le disque local. L'application affiche uniquement la liste des fichiers et fournit un lien `file://` pour les ouvrir avec l'application associée du poste. Avec Docker, configurez `DOCUMENTATION_HOST_PATH` avec le chemin absolu de ce dossier sur le poste hôte.
